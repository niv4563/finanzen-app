# Sicherheitslücken melden

Diese App ist ein privates Projekt. Wenn du eine Sicherheitslücke findest:

1. **Nicht** öffentlich als Issue melden.
2. Über GitHub eine private Meldung erstellen: Reiter **Security** › **Report a vulnerability**.
3. Bitte beschreiben: betroffene Version, Gerät, Schritte zum Nachvollziehen.

Gemeldete Lücken werden so schnell wie möglich behoben und im CHANGELOG genannt.

Was geschützt ist und wie, steht in [SICHERHEIT.md](SICHERHEIT.md).
Die App enthält keine persönlichen Daten und keine Schlüssel – bitte auch keine in Meldungen mitschicken.
